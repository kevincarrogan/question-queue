An outliner for getting thoughts out of your head without losing focus.

Every list item is an item: a first line, which the outline shows, and any lines under it, like a commit message. A question is just an item ending in ?. Items nest under whatever raised them. One markdown file, found the way git finds .git.

tabfold, as in org-mode

The outline on the left is for moving and arranging: its keys are commands and never type. The editor on the right is where you type. The key bar names the mode: OUTLINE · EDIT · NEW · MOVE. u undoes, w a s d work as the arrows, ctrl+d twice quits, and ? lists every key.
