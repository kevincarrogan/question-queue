Ticks cascade

  • space ticks or unticks, and everything with a box under it goes the same way. t adds or removes the box. New items get one, and a plain item gets one when you tick it.
  • Up: an item with boxes under it is ticked exactly when all of them are. Untick one and the ticked items above it open again.
  • Partly ticked shows [-]. Moving, adding and deleting update both the old place and the new.
  • A plain item stops the cascade: boxes under it don't count towards anything above it.

File references

  • A path:line is underlined in the outline. Click it, or press o (ctrl+o in the editor, for the cursor's line), and it opens at that line.
  • Paths are relative to the folder that holds .qq.
  • The editor is $QQ_EDITOR, else $VISUAL, else $EDITOR, else VS Code if it's installed, else vi. VS Code and the like open alongside; a terminal editor takes over until you quit it.
