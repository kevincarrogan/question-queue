The palette

VS Code's quick open with vim's command line in it. ctrl+p from either pane, or / and : in the outline, which open it with that already typed. What it works on depends on the pane you opened it from.

  • A replace needs the closing slash, so /src/app.py is still a search for that path.
  • Without flags it replaces the first match on each line. g replaces every match and i ignores case: /old/new/gi.
  • The text is literal, not a pattern, so dots and brackets in paths behave.
  • Plain words with no slash find items, wherever you are. Items are numbered in a dim gutter, in file order.
A replace, before enter
  • Before enter, it lists the items that will change, old first line struck through and the new one after it.
  • If nothing matches, enter beeps and the palette stays open.
  • u undoes a whole replace in one step.
  • Cmd+P can't reach a terminal app, so the key is ctrl+p. iTerm2 and Ghostty can map one to the other.
