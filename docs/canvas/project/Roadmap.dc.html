Ideas and next steps

0.1.0 is on PyPI. Each new front end builds on questionqueue.core
Next

qq add from the shell

Capture a thought without opening qq. It lands at the bottom, like n.

  • A VS Code task on a key: qq add "${relativeFile}:${lineNumber}", with the selected text too
  • An open qq reloads and shows it straight away
Then

MCP server

Let an LLM drive the tree through tool calls, on DocumentFile and core.ops.

  • One operation per call: load, apply, save
  • On ExternalChange, reload and retry
  • trail and next_open as "where am I" and "what next"
Then

VS Code extension

The outline beside the code, on the same file, with capture from a right-click.

  • Talks to the core through the MCP server or a small local API
  • Keeps the file exactly as qq writes it
Later

Remote and phone

Park a thought from anywhere; deal with it later at the desk.

  • Needs sync, which v1 left out on purpose
  • Capture is the phone's main job
